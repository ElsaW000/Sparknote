| 角色 | MVP | 说明 |
|------|-----|------|
| 自媒体创作者 | ✅ | 选题、脚本、素材 |
| 产品经理 | ✅ | PRD、架构、开发建议 |
| 写作搭子 | 敬请期待 | 写作前聊天 + 写完改稿 |
| 学习助手 | 敬请期待 | 知识总结、问答 |
| AI人生导师 | 敬请期待 | 人生/职业建议 |

### MVP 设计

- 验证方式：点击追踪 + 用户反馈

### 通用能力
- 知识获取（链接/图片/视频/语音）
- 知识存储（笔记 + 标签）
- 知识检索（搜索 + 语义匹配）
- 知识推荐

### Superpowers 参考
- brainstorming → 灵感讨论
- writing-plans → 任务拆分
- code review → 反馈/改稿
