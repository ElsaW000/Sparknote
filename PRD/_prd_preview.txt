# Sparknote PRD - 产品需求文档 (2026-04版)

## 1. 产品概述

**产品名称**: Sparknote
**产品定位**: 个性化创作 Agent 平台
**核心价值**: 帮助创作者快速产出高质量内容，AI 学你的风格替你写

---

## 2. 目标用户

| 用户 | 痛点 | 需求 |
|------|------|------|
| 自媒体创作者 | 产量低、没灵感、内容同质化 | AI 按我的风格产出 |
| 产品经理 | 需求文档难写、PRD 繁琐 | 自动生成 PRD/文档 |
| 写作爱好者 | 写不出来、没人给反馈 | 写作搭子引导+反馈 |
| 内容创作者 | 脚本写太久、素材难找 | 自动写脚本、找素材 |

---

## 3. 核心功能

### 3.1 知识库

**把历史变成训练数据**

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 导入文章 | 导入用户历史写的内容（微信文章、博客、文档） | P0 |
| 素材库 | 自动抓取保存的链接/图片/视频内容 | P0 |
| 文章理解 | AI 分析内容，提取风格、观点、结构 | P0 |
| 标签分类 | 自动打标签、主题分类 | P1 |

### 3.2 个性化 Agent

**AI 学你的风格**

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 风格学习 | 分析用户历史文章，学写作风格 | P0 |
| 声音定制 | 定义 Agent 的说话方式（严肃/轻松/专业） | P0 |
| 预设角色 | 提供多种角色（写作搭子、产品经理、自媒体创作者） | P0 |
| 自定义角色 | 用户自己配置 Agent 的系统提示词 | P1 |

### 3.3 生产型输出

**直接出可用内容，不是半成品**

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 脚本生成 | 输入选题，直接出可拍的脚本 | P0 |
| 文案生成 | 按平台风格输出（小红书/B站/微信） | P0 |
| PRD 生成 | 输入想法，自动出完整 PRD | P0 |
| 内容扩展 | 一句话灵感扩展成完整文章 | P0 |

### 3.4 创作工作台

**对话式交互**

| 功能 | 描述 | 优先级 |
|------|------|--------|
| AI 对话 | 基于知识库和 Agent 风格对话 | P0 |
| 快捷输入 | 一句话开始创作 | P0 |
| 历史追溯 | 引用之前的相关内容 | P0 |
| 多轮创作 | 连续对话优化内容 | P1 |

---

## 4. 用户流程

```
1. 用户注册 → 选择角色/导入历史
       ↓
2. AI 学习用户风格
       ↓
3. 开始创作：告诉 Agent 要写什么
       ↓
4. Agent 基于知识库生成内容
       ↓
5. 用户修改/发布
```

---

## 5. 角色系统

| 角色 | 能力 | 输出 |
|------|------|------|
| 自媒体创作者 | 选题、脚本、素材 | 短视频脚本、平台文案 |
| 产品经理 | 需求分析、PRD | 结构化 PRD、架构图 |
| 写作搭子 | 聊天扩展、改稿反馈 | 完整文章、修改建议 |
| 自定义 | 自己配置 | 自己定义 |

---

## 6. 数据流

```
用户输入 → 判断类型
          ↓
内容抓取 → 知识库存储
          ↓
风格学习 → 个性化 Agent
          ↓
上下文组装 → AI 生成
          ↓
输出内容 → 用户修改/发布
```

---

## 7. 技术架构

| 模块 | 技术 |
|------|------|
| 前端 | Flutter |
| 后端 | FastAPI |
| 数据库 | SQLite / PostgreSQL |
| AI | 阿里云 DashScope |
| 内容抓取 | yt-dlp + 爬虫 |

---

## 8. MVP 范围

### 第一版 (MVP)

- 用户注册 + 角色选择
- 知识库：导入 5 篇文章
- 1 个预设角色可用
- 脚本生成功能
- 对话式创作

### 第二版

- 风格学习自动化
- 多角色切换
- PRD 生成
- 素材自动抓取

### 第三版

- 自定义角色
- 历史文章批量导入
- 企业版（团队知识库）
