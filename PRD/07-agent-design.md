# Sparknote Agent 设计文档

## 1. 设计定位

### 1.1 核心价值

**一句话定位：** 创作者的 AI 灵魂伴侣，帮助捕捉、整理和扩展灵感。

**目标用户：**
- 小说作者（需要人物设定、情节扩展）
- 产品经理（需要需求整理、竞品分析）
- 内容创作者（需要素材收集、脚本撰写）
- 独立开发者（需要想法记录、技术调研）

### 1.2 与竞品差异

| 竞品 | 定位 | Sparknote Agent 差异 |
|------|------|----------------------|
| Notion AI | 全场景 AI 助手 | 专注创作场景，更垂直 |
| Cursor | 编程 AI Agent | 面向创作，非编程 |
| Character AI | 角色扮演聊天 | 严肃创作，非娱乐 |
| Flomo | 轻量笔记 | Flomo 无 Agent 能力 |

### 1.3 核心特性

1. **创作垂直**：专门针对创作场景优化（而非通用问答）
2. **记忆你的创作**：基于用户笔记内容进行对话
3. **自定义灵魂**：用户可定制 AI 的性格、语气、风格
4. **轻量交付**：无需复杂配置，开箱即用

## 2. 交互框架

### 2.1 入口形态

**入口位置：** 笔记详情页 → "灵感工作台" 按钮

**交互方式：**
- 在笔记页面点击"灵感工作台" → 进入 AI 对话
- 对话基于当前笔记内容展开

### 2.2 对话模式

```
┌─────────────────────────────────────┐
│           笔记详情页                │
│  ┌─────────────────────────────┐   │
│  │ 笔记内容...                 │   │
│  └─────────────────────────────┘   │
│                                     │
│  [灵感工作台]  ← 点击进入 Agent    │
└─────────────────────────────────────┘
                    ↓
┌─────────────────────────────────────┐
│         灵感工作台（Agent）         │
│  ┌─────────────────────────────────┐│
│  │ 对话历史                        ││
│  │                                 ││
│  │                                 ││
│  ├─────────────────────────────────┤│
│  │ 🤖 你的创作搭子                 ││
│  ├─────────────────────────────────┤│
│  │ 输入框...              [发送]  ││
│  └─────────────────────────────────┘│
└─────────────────────────────────────┘
```

### 2.3 Agent 切换

**底部导航/设置入口：**
- 用户可以切换当前 Agent 的"角色"
- 不同角色有不同 system prompt
- 切换后不影响对话历史，但影响后续回复风格

## 3. Agent 角色模板

### 3.1 预设角色

| 角色 ID | 名称 | 描述 | 适用场景 |
|---------|------|------|----------|
| creator | 创作搭子 | 陪你聊天，帮你扩展灵感 | 灵感枯竭、想找人讨论 |
| coach | 写作教练 | 给你写作建议，帮你改稿 | 写完后需要反馈 |
| brainstorm | 头脑风暴 | 快速生成大量创意点子 | 需要很多想法 |
| editor | 文字编辑 | 帮你润色、改写、简化 | 稿件需要优化 |
| custom | 自定义 | 完全由你定义 | 有特殊需求 |

### 3.2 角色 Prompt 示例

**创作搭子 (creator)：**
```
你是 Sparknote 的创作搭子，擅长帮用户扩展想法、讨论情节。
- 不要直接给答案，要引导用户自己思考
- 善于提问，帮助用户挖掘更多细节
- 语气温暖，鼓励为主
- 如果用户遇到瓶颈，给出 2-3 个方向性建议
```

**写作教练 (coach)：**
```
你是资深写作教练，擅长点评文章结构、语言风格。
- 给用户具体、可执行的修改建议
- 先肯定优点，再指出改进点
- 用建设性语言，避免打击用户信心
- 如果内容质量已经很高，直接肯定
```

**头脑风暴 (brainstorm)：**
```
你是创意机器，擅长在短时间内抛出大量点子。
- 不要过滤，先发散再收敛
- 每个想法给一句话描述
- 如果用户选择某个方向，再深入展开
- 目标是数量，质量和可行性是第二步
```

### 3.3 自定义模式

用户可以选择"自定义"，自己编写 system prompt：
- 提供一个文本框
- 内置常用提示词模板（可点击插入）
- 预览效果

## 4. 功能架构

### 4.1 核心功能矩阵

| 功能 | P0 | 说明 |
|------|-----|------|
| 角色切换 | ✅ | 切换 Agent 角色 |
| 基于笔记对话 | ✅ | 对话时注入笔记内容 |
| AI 回复 | ✅ | 调用 AI 生成回复 |
| 角色管理 | ✅ | 查看/切换预设角色 |
| 自定义 Prompt | P1 | 用户自行编写 system prompt |
| 对话导出 | P2 | 将会话保存为笔记 |
| 角色创建 | P2 | 创建自己的角色 |

### 4.2 用户流程

```
1. 进入笔记详情
       ↓
2. 点击"灵感工作台"
       ↓
3. 选择 Agent 角色（默认：创作搭子）
       ↓
4. 开始对话（AI 已了解笔记内容）
       ↓
5. 可以随时切换角色
       ↓
6. 对话结束，可以保存为新笔记
```

### 4.3 数据流

```
用户输入 → 注入 System Prompt → 注入笔记内容 → AI 调用 → 返回回复
                ↑                        ↑
         用户选择的角色              当前笔记内容
```

## 6. 技术实现

### 6.1 数据库设计

```sql
-- 用户 Agent 配置
ALTER TABLE user ADD COLUMN agent_template VARCHAR(50) DEFAULT 'creator';
ALTER TABLE user ADD COLUMN agent_custom_prompt TEXT;

-- 角色模板表（预设）
CREATE TABLE agent_template (
    id VARCHAR(50) PRIMARY KEY,
    name VARCHAR(50),
    description TEXT,
    system_prompt TEXT,
    icon VARCHAR(20)
);
```

### 6.2 API 设计

```
GET  /agent/templates         # 获取预设角色列表
GET  /agent/config            # 获取用户当前配置
PUT  /agent/config            # 更新用户配置（选择角色/自定义）
```

### 6.3 AI 调用改造

```python
# 原逻辑
messages = [
    {"role": "system", "content": "You are a helpful assistant."},
    {"role": "user", "content": prompt}
]

# 新逻辑
user_template = user.agent_template
system_prompt = TEMPLATES[user_template].prompt

# 如果用户自定义了
if user.agent_custom_prompt:
    system_prompt = user.agent_custom_prompt

messages = [
    {"role": "system", "content": system_prompt},
    {"role": "user", "content": prompt_with_note_content}
]
```
