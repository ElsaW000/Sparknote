## 3. 通用能力层

### 知识获取
- 文本：直接存入
- 链接：自动抓取页面
- 图片：OCR + 理解
- 视频：提取字幕 + 关键帧
- 语音：转文字

### 知识存储
- 存入笔记
- 标签分类
- 记录来源

### 知识检索
- 关键词搜索
- 语义相似匹配
- 时间/标签筛选

### 知识推荐
- 基于当前话题推荐相关素材
- 过去相关灵感

### 对话扩展
- 帮你打开思路
- 不是直接给答案，而是引导思考

## 8. 参考：Superpowers 工作流

> 来源：https://github.com/obra/superpowers
> 一个给编程 Agent 用的完整开发工作流

### 核心流程

1. **brainstorming** — 先讨论设计，不直接写代码
2. **writing-plans** — 拆成小任务（2-5分钟一个）
3. **subagent-driven-development** — 子 Agent 并行执行任务
4. **test-driven-development** — TDD 流程

### 可借鉴的点

| Superpowers (编程) | Sparknote (创作) |
| ---------------- | -------------- |
| brainstorming    | 灵感讨论           |
| writing-plans    | 任务拆分           |
| subagent-driven  | 子任务执行          |
| code review      | 反馈/改稿          |
