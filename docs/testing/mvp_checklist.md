# Sparknote MVP 测试清单

说明：
- `AI测试`：适合通过脚本、接口验证、日志检查、构建检查完成。
- `人工测试`：需要在浏览器或页面里实际点击、观察和判断。

| 模块 | AI测试 | 人工测试 |
| --- | --- | --- |
| 启动与可访问性 | [ ] `http://127.0.0.1:8000` 返回 `200`。 | [ ] 打开首页无白屏、无崩溃、无明显乱码。 |
| 登录页加载 | [ ] 登录页资源加载成功，无接口 4xx/5xx。 | [ ] 登录页布局正常，左侧品牌区和右侧登录卡片显示正常。 |
| 注册页加载 | [ ] `#/register` 路由可访问，验证码接口正常返回。 | [ ] 注册页能正常打开，字段完整，无遮挡、无错位。 |
| 登录页身份卡 | [ ] 页面构建产物包含身份卡点击逻辑与场景页代码。 | [ ] 点击底部身份卡，会从右往左进入沉浸式场景介绍页。 |
| 沉浸式场景页 | [ ] 页面构建成功，切换动画无报错。 | [ ] 左上角有“返回登录/注册”，底部 CTA 可进入注册页。 |
| 注册校验 | [ ] 接口对空邮箱、非法邮箱、密码不一致、空验证码返回合理错误。 | [ ] 注册页输入错误内容时，错误提示显示正确。 |
| 注册成功链路 | [ ] 注册接口成功后，登录接口返回 token。 | [ ] 注册成功后自动进入主页。 |
| 登录成功链路 | [ ] 登录接口成功返回 token 并可写入本地存储。 | [ ] 输入正确账号密码后成功进入主页。 |
| 登录失败链路 | [ ] 错误账号密码返回明确错误信息。 | [ ] 登录失败时页面提示清晰，不白屏。 |
| 主页加载 | [ ] `/notes` 所需接口正常返回。 | [ ] 主页三栏布局正常，统计、搜索、列表、侧栏都能看到。 |
| 快速输入 | [ ] 创建笔记接口返回成功，新笔记可被查询到。 | [ ] 底部快速输入发送后，笔记立即出现在列表。 |
| 长笔记创建 | [ ] 新建笔记接口成功，内容持久化。 | [ ] 新建长笔记后保存成功，刷新后仍能看到。 |
| 笔记编辑 | [ ] 更新笔记接口成功，返回内容正确。 | [ ] 编辑已有笔记并保存后，页面内容同步更新。 |
| 笔记删除 | [ ] 删除接口成功，后续查询不再返回该笔记。 | [ ] 删除笔记后，列表中该笔记消失。 |
| 搜索与筛选 | [ ] 搜索接口或本地筛选逻辑无报错。 | [ ] 搜索关键词后，列表结果符合预期。 |
| 热力图/回顾/标签 | [ ] `/stats/heatmap`、`/review/daily`、标签建议接口正常返回。 | [ ] 热力图、今日回顾、标签区域渲染正常，无空白异常。 |
| 灵感工作台入口 | [ ] 工作台相关接口存在且响应正常。 | [ ] 点击“灵感工作台”能进入工作台页面。 |
| 工作台消息发送 | [ ] 会话创建、消息发送、消息查询接口成功。 | [ ] 工作台发消息后，右侧出现消息和 AI 回复或失败兜底文案。 |
| 工作台总结 | [ ] 总结接口成功返回 summary 或明确失败信息。 | [ ] 点击“生成总结”后，页面有结果反馈，不会卡死。 |
| 编码与乱码 | [ ] 接口返回内容按 UTF-8 解码，无 mojibake。 | [ ] 登录、注册、主页、工作台页面中文显示正常，无乱码。 |
| 验证码显示 | [ ] `/auth/captcha` 返回字段完整。 | [ ] 注册页验证码题目显示正常，不出现乱码。 |

| 退出登录 | [ ] 清理 token 后受保护接口返回未授权。 | [ ] 点击退出登录后回到登录页，且不能直接回到主页。 |
| 异常网络场景 | [ ] 后端关闭时前端请求失败可捕获。 | [ ] 后端不可用时页面给出可读提示，不白屏。 |
| AI 服务异常 | [ ] 外部 AI 不可达时后端返回兜底内容或错误码。 | [ ] AI 不可用时工作台显示失败提示，不影响其他页面。 |
| 桌面端回归 | [ ] Web 构建成功，无新增阻塞错误。 | [ ] 跑通“登录 -> 新建笔记 -> 工作台 -> 退出登录”。 |
| 注册回归 | [ ] 注册后接口链路完整无断点。 | [ ] 跑通“注册 -> 自动登录 -> 新建笔记 -> 工作台”。 |
| 缓存回归 | [ ] 新构建产物已更新到 `build/web`。 | [ ] 无痕窗口访问时仍能看到最新页面，不吃旧缓存。 |

## 建议执行顺序

1. 先跑 `AI测试` 中的启动、登录、注册、笔记、工作台主链路。
2. 再跑 `人工测试` 中的登录、注册、主页、工作台完整流程。
3. 最后做异常场景和缓存回归。
