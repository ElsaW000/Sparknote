# MirrorMe 需求真实性验证计划

> 基于 `ai-founder-idea-guide`：Idea 阶段只回答一个问题：这件事值不值得继续做。代码、原型、海报和产品界面只能作为访谈道具，不能当作需求已经成立的证据。

## 1. 当前不能直接判定为真需求

MirrorMe 当前表达是：

- 多形式输入：文字、图片、录音、网页。
- 随手记录：不用先想清楚，先丢给 MirrorMe。
- 多维分析：主题、情绪、模式、下一步。
- 不只是知识库，也是镜子。
- 可定制口吻、角度和专属 Skill。
- 像一个 AI 知己，陪用户从混沌到清晰。

这些是产品主张，不是用户证据。现在最大的风险是：我们讲的是创始人想象中的“自我复盘价值”，但用户真实痛点可能只是“资料太散”“写作素材难找”“AI 整理不准”“懒得记录”，甚至他们可能根本不想被分析。

## 2. 先把需求改写成可证伪假设

### 主假设

在持续写作、内容创作、产品思考或个人复盘的人群中，有一类用户每周至少 3 次产生碎片化想法或素材，但因为输入形式混杂、缺少回看机制、现有工具整理成本高，导致这些内容无法转化为选题、判断或行动。他们愿意尝试一个能接收多形式输入，并从主题、情绪、模式、下一步等维度帮助回看的 AI 工具。

### 必须验证的子假设

1. 用户真的高频产生碎片，而不是偶尔记录。
2. 碎片丢失或无法复用造成了可描述的损失。
3. 用户现在已经在用某种 workaround，例如微信收藏、备忘录、flomo、Notion、Obsidian、飞书文档、文件夹、截图相册、语音备忘录。
4. 用户对现有 workaround 有明确不满，而不是已经满意。
5. “多维分析”比“更好的搜索/标签/总结”更有价值。
6. 用户愿意把私人想法、录音、图片交给 AI 处理。
7. “镜子/知己/专属 Skill”是用户能理解并愿意使用的表达，而不是我们自嗨的包装。
8. 用户有明确的触发时刻会打开这个工具，而不是觉得概念好但不会用。

## 3. 最强反对意见

验证时要主动找反证：

- 这可能只是“记录焦虑”，不是强需求。
- 用户说喜欢复盘，但真实行为是不复盘。
- flomo、Notion、Obsidian、微信收藏已经足够好。
- 用户不想被 AI 分析私人记录，尤其是情绪和内心想法。
- “知己”可能太虚，用户只想要更快的整理和搜索。
- 多形式输入会增加复杂度，真正高频的可能只有文字或截图。
- 定制 Skill 听起来高级，但普通用户可能不知道怎么配置。
- 付费意愿可能弱，因为个人知识管理工具替代品太多。

## 4. 目标访谈人群

先不要泛泛找“创作者”。分 3 个可触达细分人群，每组至少 5 人。

### A. 小红书/视频内容创作者

- 每周稳定产出内容。
- 经常收藏选题、截图、网页、评论反馈。
- 有“素材很多但产出时找不到/串不起来”的经历。

### B. 产品经理/独立开发者

- 经常记录用户反馈、竞品观察、产品想法。
- 需要把零散信息转化为需求判断或 Roadmap。
- 现在已有文档、表格、Issue、Notion 等流程。

### C. 长期自我复盘用户

- 有日记、周报、心理咨询、教练、Notion Life OS、flomo 等习惯。
- 关注自我理解、情绪模式、成长复盘。
- 愿意讨论私人记录交给 AI 的边界。

## 5. 访谈问题

只问过去行为，不问“你会不会用”。

### 最近一次事件

1. 最近一次你记录一个想法、素材、情绪或灵感是什么时候？
2. 当时触发它的场景是什么？
3. 你记录在哪里？为什么选那个地方？
4. 后来你有没有再用到它？如果没有，为什么？
5. 如果用到了，它最后变成了什么：选题、文章、产品判断、行动、还是只是存档？

### 当前 workaround

6. 你现在用哪些工具保存这些碎片？
7. 文字、图片、录音、网页分别怎么处理？
8. 你最讨厌当前流程的哪一步？
9. 你有没有尝试过换工具？为什么留下或放弃？
10. 如果什么都不改，会有什么实际影响？

### 严重性

11. 过去一个月，有没有因为素材找不到、想法断掉、复盘失败而影响产出或判断？
12. 这件事大概浪费了多少时间？
13. 它带来的主要损失是效率、情绪、收入、创作质量，还是决策质量？

### 对 MirrorMe 概念的反应

先不展示完整产品，只说一句：

> “你可以把文字、图片、录音、网页随手丢进去。之后 AI 会按主题、情绪、模式、下一步帮你回看。它不只是知识库，更像一面镜子，也可以调成你的专属分析角度。”

然后问：

14. 这句话里哪一部分你立刻理解？
15. 哪一部分你觉得虚？
16. 如果只保留一个能力，哪个最有用？
17. 你会担心什么？
18. 这和你现在工具相比，必须好到什么程度你才会切换？

## 6. 证据记录表

每次访谈后记录：

| 字段 | 记录 |
| --- | --- |
| 用户类型 | 创作者 / 产品经理 / 复盘用户 / 其他 |
| 最近一次真实事件 | 具体场景 |
| 频率 | 每天 / 每周 / 偶尔 |
| 当前工具 | 具体工具和流程 |
| 当前不满 | 原话 |
| 损失强度 | 时间 / 情绪 / 产出 / 决策 |
| 最有价值能力 | 输入 / 分析 / 镜子 / Skill / 知己 |
| 最大顾虑 | 隐私 / 准确性 / 麻烦 / 不信任 / 不愿付费 |
| 支持需求的证据 | 真实行为 |
| 反驳需求的证据 | 真实行为 |

## 7. 阶段性判定标准

先做 15 个访谈，每 5 个复盘一次。

### 可以继续

满足以下大部分条件：

- 至少 10/15 人能讲出最近 7 天内的真实碎片记录场景。
- 至少 8/15 人明确说当前流程导致找不到、用不上、复盘不了。
- 至少 6/15 人已经投入明显成本解决，包括付费工具、复杂模板、固定流程或人工整理。
- 至少 5/15 人对“多维回看”有强反应，而不只是喜欢“AI 总结”。
- 至少 5/15 人愿意拿真实材料试一个轻量原型。

### 需要修改

出现以下情况：

- 用户只想要统一收集箱，不想要“镜子/知己”。
- 用户只在意搜索和标签，不在意多维分析。
- 用户只愿意处理文字，不愿意导入图片/录音。
- 用户更适合某个垂直场景，例如“内容选题库”或“产品反馈分析”，而不是泛化自我复盘。

### 应该停止或转向

出现以下情况：

- 多数用户没有高频记录行为。
- 用户现有工具足够满意。
- 用户无法说出具体损失。
- 用户喜欢概念，但没有真实使用触发时刻。
- 用户强烈抗拒把私人材料交给 AI。

## 8. 下一步行动

1. 先定一个细分人群，不要同时验证所有人。建议从“小红书/内容创作者”或“产品经理/独立开发者”二选一。
2. 招募 5 个访谈对象，问真实过去事件。
3. 每次访谈后填证据记录表。
4. 5 个访谈后做一次反证复盘：哪些地方说明这是伪需求？
5. 如果信号不足，不继续做功能；只改假设。
6. 如果信号足够，再做一个轻量原型，只验证一个核心交互：用户丢进一组碎片后，MirrorMe 能否生成让用户觉得“它真的看懂我了”的回看结果。

## 9. 当前最小原型不应该做全产品

如果进入原型阶段，只做一个核心交互：

1. 用户上传或粘贴 5-10 条真实碎片。
2. MirrorMe 输出 4 块内容：主题、情绪、反复模式、下一步问题。
3. 用户标记：准 / 不准 / 有启发 / 没价值。
4. 访谈用户为什么这么标记。

这个原型要证明的不是“功能能跑”，而是：用户是否真的从自己的碎片里看到了有价值的自己。
