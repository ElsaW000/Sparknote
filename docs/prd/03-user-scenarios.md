# Spark Vault 用户使用场景

版本：v0.2 评审稿  
日期：2026-05-27

## 1. 场景一：突然想到一个观点

用户在路上、睡前、散步时突然想到一个观点，不方便打字。

用户需要：

- 快速打开 App。
- 用口述记录想法。
- 自动转成文字。
- 稍后整理成清晰笔记。

产品支持：

- Capture 入口。
- 口述转文字。
- AI 整理正文。
- AI 总结要点和标签。

## 2. 场景二：读书时摘录一段话

用户读纸质书或电子书时看到一段有价值的内容。

用户需要：

- 输入或粘贴摘录。
- 标记书名、作者、页码。
- 添加自己的理解。
- 保存后以后能搜索到。

产品支持：

- Capture 手动输入。
- Book 来源类型。
- 元数据字段。
- Library 搜索和标签筛选。

## 3. 场景三：看到网页内容想保存

用户在浏览器中看到一段有启发的内容。

用户需要：

- 粘贴网页片段。
- 保存网页标题或链接。
- 自动总结。
- 后续按主题找回。

产品支持：

- Browser 来源类型。
- Source URL。
- AI 总结。
- 标签筛选。

## 4. 场景四：口述了一段很乱的想法

用户口述内容有重复、停顿、顺序混乱。

用户需要：

- 保留原始口述。
- 得到一版更清晰的整理文本。
- 得到摘要和标签。
- 自己确认后保存。

产品支持：

- originalText 保留原文。
- cleanedText 保存整理后正文。
- aiSummary 保存总结。
- tags 保存标签。

## 5. 场景五：想找回过去的想法

用户想查找之前保存过的一条想法，但只记得关键词或主题。

用户需要：

- 搜索关键词。
- 按来源筛选。
- 按标签筛选。
- 只看收藏内容。

产品支持：

- Library 搜索。
- Source filter。
- Tags filter。
- Starred only。

## 6. 场景六：整理一批相关材料

用户围绕一个主题保存了多条内容，希望先合并整理。

用户需要：

- 多选相关 fragment。
- 合并成一条综合笔记。
- 保留来源线索。

产品支持：

- Merge Fragments。
- 合并后生成新 fragment。
- 标签去重。

## 7. 场景七：回看 AI 整理历史

用户想查看之前整理过的内容，而不是重新生成。

用户需要：

- 找到历史整理结果。
- 打开整理详情。
- 继续编辑或复用。

产品支持：

- Library 中的整理历史入口。
- 或 AI 页面中的最近整理入口。

## 8. 场景优先级

| 优先级 | 场景 |
| --- | --- |
| P0 | 手动输入并保存 |
| P0 | 口述转文字并保存 |
| P0 | 大模型整理和总结 |
| P0 | Library 找回内容 |
| P1 | 多条内容合并 |
| P1 | 查看整理历史 |
| P2 | OCR / 截图识别增强 |
