# Spark Vault PRD 文档目录

更新时间：2026-05-27

这个目录用于集中存放 Spark Vault 当前阶段的产品文档。`docs/prd` 表示 `docs` 下面的 `prd` 文件夹，不是独立于 `docs` 之外的目录。

## 文档清单

| 文件 | 用途 |
| --- | --- |
| `01-prd.md` | 当前版本产品需求文档，包含 DDL、功能范围、Tab 调整建议 |
| `02-product-design.md` | 产品设计文档，说明产品结构、模块职责、交互原则 |
| `03-user-scenarios.md` | 用户使用场景，描述用户在什么情况下使用产品 |
| `04-user-journeys.md` | 用户使用路径，描述从打开 App 到完成任务的具体流程 |

## 当前评审重点

1. 当前版本 DDL 是否合理。
2. 口述转文字是否作为 v0.2 必做能力。
3. 大模型能力是否只做“整理和总结”，暂不做延展续写。
4. 底部 Tab 是否从 5 个调整为 4 个。
5. Archive 是否取消独立 Tab，降级为历史记录入口。
