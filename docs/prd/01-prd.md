## 2. 产品定位

Spark Vault 是一个面向个人知识整理的手机工具。它帮助用户把随时产生的想法、口述内容、书摘、网页片段和截图文本整理成结构清晰、可再次使用的笔记。

当前产品的核心不是“帮用户写长文”，而是：

- 快速收集原始材料。
- 把凌乱文字整理清楚。
- 提炼摘要和标签。
- 保留来源和个人想法。
- 方便后续搜索和复用。

## 3. 当前核心功能范围

### 3.1 必做功能

- 手动输入文字。
- 口述转文字。
- 保存碎片笔记。
- 大模型整理文字。
- 大模型总结内容。
- 自动生成标签。

- 本地历史记录查看。

### 3.2 暂不做功能

- 自动生成完整论文或完整文章。
- 多设备云同步。
- 账号体系。
- 团队协作。
- 付费订阅。
- App Store / Google Play 上架合规完整流程。

## 4. Tab 调整建议

当前版本有 5 个 Tab：

- Dashboard
- Library
- Capture
- Workspace
- Archive

问题：

- Archive 只是历史结果和设置，不应该占用一个一级 Tab。
- 手机底部 Tab 越多，越难形成清晰主路径。
- 用户最常用的是“记录、整理、查找”，不是“归档”。
- Settings 和 Archive 混在一个 Tab 中，职责不清晰。

### 4.1 推荐 Tab 方案

建议调整为 4 个主 Tab：

| Tab | 新名称 | 职责 |
| --- | --- | --- |
| Home | 首页 | 指标、最近内容、快捷入口 |
| Capture | 记录 | 文字输入、口述转文字、截图/OCR 后续入口 |
| Library | 笔记库 | 搜索、筛选、编辑、收藏、历史整理结果 |
| AI | 整理 | 大模型整理、总结、标签生成 |

Archive 调整为二级入口：

- 放入 Library 的“历史整理”。
- 或放入 AI 的“整理历史”。
- Settings 放入 Home 右上角或 Library 二级页面。

### 4.2 暂定结论

Archive 不建议继续作为独立底部 Tab。当前 PRD 按“Archive 降级为二级入口”设计。

## 5. 口述转文字

### 5.1 使用目标

用户在走路、开车后停车、读书时、临时想到观点时，可以直接按住或点击录音，把口述内容转成文字，进入后续整理流程。

### 5.2 功能要求

- Capture 页面提供“口述记录”入口。
- 用户点击后开始录音。
- 用户停止后生成文字草稿。
- 用户可以编辑转写结果。
- 用户确认后保存为 fragment。
- 转写结果可以继续交给大模型整理和总结。

### 5.3 字段要求

口述生成的 fragment 至少包含：

- originalText：转写后的文字。
- sourceType：Voice。
- sourceTitle：默认“口述记录”或用户自定义标题。
- userComment：用户可补充。
- tags：由大模型或本地 fallback 生成。
- aiSummary：由大模型或本地 fallback 生成。
- createdAt / updatedAt。

### 5.4 异常处理

- 用户未授权麦克风时，提示开启权限。
- 录音为空时，不创建 fragment。
- 转写失败时，保留录音失败提示，不让页面崩溃。
- 网络不可用时，提示“暂时无法转写，可先手动输入”。

## 6. 大模型整理和总结

### 6.1 当前只做两件事

本阶段大模型只负责：

1. 文字整理。
2. 内容总结。

不做：

- 延展续写。
- 生成完整文章。
- 编造用户没有说过的观点。
- 复杂研究报告。

### 6.2 文字整理定义

输入可能是口述、粘贴文本、OCR 文本或零散想法。大模型需要把它整理成更清晰的表达，但不能改变原意。

整理输出包括：

- 清理口语重复。
- 修正明显断句。
- 合并碎片句子。
- 保留用户原始观点。
- 输出一版“整理后正文”。

### 6.3 内容总结定义

总结输出包括：

- 一句话摘要。
- 3 到 5 个要点。
- 3 到 5 个标签。

### 6.4 推荐输出结构

```text
整理后正文：
...

一句话摘要：
...

要点：
1. ...
2. ...
3. ...

标签：
#标签1 #标签2 #标签3
```

### 6.5 保存规则

大模型返回后，用户必须能看到并确认：

- 原始文本。
- 整理后文本。
- 摘要。
- 标签。

用户点击保存后，再写入 Library。

## 8. 当前页面需求

### 8.1 Home

展示：

- 最近记录。
- 总笔记数。
- 收藏数。
- 标签数。
- 快捷入口：文字记录、口述记录、AI 整理。

### 8.2 Capture

提供三个入口：

- 手动输入。
- 口述转文字。
- OCR / 截图识别，后续增强。

当前优先级：

1. 手动输入。
2. 口述转文字。
3. OCR。

### 8.3 Library

负责所有保存后的内容管理：

- 搜索。
- 筛选。
- 标签。
- 收藏。
- 编辑。
- 删除。
- 查看整理历史。

### 8.4 AI

负责对输入内容进行处理：

- 整理文字。
- 总结内容。
- 生成标签。
- 保存结果。
- 查看最近整理。

AI 页面不负责长文续写。

## 9. 验收清单

### 9.1 文字记录

- 输入一段文字。
- 点击整理和总结。
- 展示整理后正文、摘要、标签。
- 保存后 Library 可见。

### 9.2 口述记录

- 点击口述入口。
- 完成录音。
- 得到转写文字。
- 用户可编辑转写结果。
- 可继续整理和总结。
- 保存后 Library 可见。

### 9.3 Tab 调整

- 底部不再默认显示 Archive。
- 历史整理记录可从 Library 或 AI 进入。
- 设置不混在历史列表主入口中。
