# Sparknote 进度日志

- 记录时间: 2026-03-17

## 总结
- 今天的重点是首页与设置体系的 UI 收敛，不再只是补功能，而是开始统一信息架构、字体比例、卡片节奏和左右分栏语言。
- 首页的“灵感流”已从偏拥挤的操作台，收敛成更清晰的三栏工作台：首页主流负责笔记，右栏负责搜索/日历记录/今日回顾，左栏负责导航与索引。
- 长笔记编辑弹窗已补齐图片和文档上传能力，和底部碎片输入的附件能力保持一致。

## 今日完成
- 首页结构收敛
  - 将桌面端搜索框移入右侧工具栏顶部，弱化其对中间主信息流的干扰。
  - 将标题旁提示文案改为轻量说明，不再占用一整块垂直空间。
  - 收紧顶部统计区、搜索区和正文区的节奏，提升一屏信息密度。
- 设置与文档体系重构
  - `设置` 页面已重构为统一左右两栏布局，左侧为一级导航，右侧为单一详情区。
  - `API连接` 页面已拆为 `API文档`，改成知识库/说明书形态，左侧服务目录，右侧平台文档内容。
  - 设置页已纳入：个人资料、风格、API、AI Provider。
- 设计规范收敛
  - 统一主要页面的标题、正文、说明文字级别。
  - 大容器圆角统一收敛到 24px 左右。
  - 首页笔记卡片改为固定高度预览，标题单行省略、正文单行省略、标签移入按钮区。
- 今日回顾改造
  - 不再直接拼接当天内容长句。
  - 改为更像 AI 摘要的短句/关键词式回顾，优先提炼标题和标签。
- 长笔记能力补齐
  - 在“新建笔记 / 编辑笔记”弹窗中增加 `上传图片`、`上传文件`。
  - 支持待上传附件显示与移除。
  - 笔记保存成功后自动上传所选附件。
- 首页拥挤感修正
  - 拉大桌面端笔记卡片之间的纵向间距。
  - 增加笔记列表底部安全留白，避免最后一张卡片被底部输入框遮挡。
  - 将底部输入框改成更轻的玻璃感表面，降低压迫感。
- 今日新增 UI 收敛
  - 主页中间与右栏之间新增可拖拽分隔，右侧工具栏宽度可手动调节。
  - 长笔记弹窗进一步放宽，并把上传图片/上传文件按钮与表单主视觉线重新对齐。
  - 右下角“灵感工作台”从重色块卡片改成浮动胶囊入口，减轻页面压舱感。
  - 灵感工作台入口升级为分步弹窗：
    - 第一步选择模式（通用 / 产品 / 写作 / 视频）
    - 第二步选择笔记素材（支持单选与多选）
    - 多选时会先生成整合草稿，再进入工作台
- 今日补上的关键闭环
  - 工作台会话与草稿笔记建立可恢复绑定，不再是“一次性”页面。
  - `今日回顾` 中如果命中进行中的草稿，会直接回到对应工作台，而不是只打开普通笔记。
  - 工作台右上角新增 `历史灵感` 入口，可查看并继续编辑历史草稿。
- 本地测试流程收口
  - 本地启动脚本改为隐藏单实例启动，不再反复弹出多个后端黑窗口。
  - 停止脚本改为只停止 Sparknote 自己的后端进程，不再粗暴结束所有 Python 进程。
  - 去掉了本机上会触发权限提示的额外进程扫描逻辑，避免启动时出现无关噪音。

## 重点 UI 收敛结论
- 当前设计语言已经基本形成三条主线：
  - 左侧: 导航与索引
  - 中间: 核心笔记流
  - 右侧: 辅助工具与回顾
- 设置页和 API 文档页已经统一为同一套左右联动模式，后续可继续复用到更多配置/文档型页面。
- 首页还需要继续做一轮按钮区收纳和密度优化，但大的方向已经从“杂糅堆叠”收敛为“职责分栏”。
