# Sparknote 架构确认记录

- 记录时间: 2026-02-28 21:23:29 +08:00

## 结论（已确认）
- 后端是 `FastAPI + SQLModel`，数据库入口为 `DATABASE_URL`。
- 默认数据库是本地 SQLite：`sqlite:///./sparknote.db`。
- 移动端当前通过 HTTP 调用后端接口（`/auth/login`、`/notes` 等），不是直接调用 Supabase SDK。
- 因此当前运行时方案为：`Flutter -> FastAPI -> SQLite/PostgreSQL`。

## 证据文件（当前实现）
- `backend/main.py`：`DATABASE_URL` 默认 SQLite，`create_engine` 基于该变量。
- `mobile/pubspec.yaml`：依赖中无 `supabase_flutter`。
- `mobile/lib/pages/login.dart`：使用 `http` 调用 `BACKEND_URL/auth/login`。
