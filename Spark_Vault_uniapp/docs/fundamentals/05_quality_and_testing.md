## 手工走查用例

### Home Tab
- 首页统计数字正常显示（空数据时显示 0，不崩溃）
- FAB 快速录入：点击后跳入 Library Editor（S2），保存后返回首页统计更新
- 月度报告入口：跳转报告历史页（S4）

### Library Tab
- 片段列表加载：空数据时显示空态，不崩溃
- 两级筛选 chip：content_type 筛选（全部 / 个人 / 参考）+ subtype 筛选（想法/日记/录音/书摘/网页/文件）联动正常
- 片段详情编辑（S2）：id 参数正确传递
- 内容浏览器（S3）：进入/返回正常

### Chat Tab
- 会话列表：空状态正确，`+ 新建会话` 按钮可用
- 新建会话：底部弹出模式选择（普通对话 / 苏格拉底式引导 / 创作辅助），选择后跳转 session 页（S1b）
- 已有会话：点击跳转 session 页（S1）
- Session 页：消息可发送、AI 有回复、可返回

### Me Tab
- 用户信息卡正常显示
- 升级套餐按钮可点（跳转或弹出）
- 技能设置（S6）：技能列表加载，toggle 开关可操作，苏格拉底默认 OFF
- 退出登录：有确认弹窗，不直接退出

### 报告流程
- 报告历史列表（S4）：按月分组显示，空数据显示空态
- 生成报告（S4b）：显示"预计生成时间：30秒"，生成后跳转详情
- 报告详情（S5）：内容可滚动，反馈按钮（👍 / 👎）可点

### Tab 导航
- switchTab 在 4 个主 Tab 间切换：无 dead link，无参数丢失
- navigateTo 跳子页：参数通过 query string 正确传递，返回后状态正确

## 回归策略
- 逻辑层变更：必须补充/更新 `tests/` 下对应测试
- 路由变更：必须核对 `pages.json` 与页面文件一致
- content_type / subtype 变更：需同步更新 Library 筛选逻辑与 AI 提示词
