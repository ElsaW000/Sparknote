# 产品范围（当前版本）

状态: Active
更新时间: 2026-06-01

## 一句话定位
帮助用户发现自身思维习惯与成长轨迹的**个人成长反思工具**。

## 用户与场景
- 有写作/记录习惯的个人用户：沉淀想法、日记、书摘等碎片，借助 AI 定期反思。
- 知识管理用户：区分「个人内容」（反思原料）与「参考内容」（知识库），分类沉淀。
- 反思型用户：通过 AI 对话探索记忆偏差，生成洞察报告，回顾成长轨迹。

## 核心数据模型：Fragment（片段）
片段分两类，决定 AI 处理方式：

| `content_type`       | 子类型                        | AI 用途                  |
|----------------------|-------------------------------|--------------------------|
| `personal_content`   | 💡想法 / ✍日记 / 🎙录音       | 分析记忆偏差，作为反思原料 |
| `reference_content`  | 📖书摘 / 🌐网页 / 📎文件      | 构建知识库，不参与偏差分析 |

## MVP 功能边界
- 必做:
  - 片段录入（想法/日记/书摘/网页/文件，含录音转文字）
  - 片段库浏览、筛选、详情编辑
  - AI 对话（普通对话 / 苏格拉底式引导 / 创作辅助，3 种模式）
  - 月度洞察报告生成与历史查看
  - 技能/个性化设置
- 暂缓:
  - 多账号协作
  - 高级权限体系
  - 复杂离线同步冲突处理

## 页面与能力映射

### 底部 Tab（4 个，固定导航）

| Tab      | 路由                      | 核心功能                              |
|----------|---------------------------|---------------------------------------|
| Home     | `pages/01-home/index`     | 片段统计、快速录入 FAB、月度报告入口  |
| Library  | `pages/02-library/index`  | 片段列表（两级筛选）、片段详情编辑    |
| Chat     | `pages/03-chat/index`     | 会话列表、新建会话（3 种模式选择）    |
| Me       | `pages/04-me/index`       | 用户信息、套餐、技能设置、退出登录    |

### 子页面（navigateTo，从 Tab 页跳入）

| 编号 | 路由                              | 来源          |
|------|-----------------------------------|---------------|
| S1   | `pages/03-chat/session`           | Chat → 已有会话 |
| S1b  | `pages/03-chat/session`           | Chat → 新建会话 |
| S2   | `pages/02-library/editor`         | Library → 新建/编辑片段 |
| S3   | `pages/02-library/browser`        | Library → 全部内容浏览 |
| S4   | `pages/01-home/report/index`      | Home → 月度报告历史 |
| S4b  | `pages/01-home/report/generate`   | Home → 生成本月报告 |
| S5   | `pages/01-home/report/detail`     | 报告列表 → 报告详情 |
| S6   | `pages/04-me/skills`              | Me → 技能设置 |

## 非功能要求
- 页面响应: 常规交互 < 300ms（本地操作）
- 稳定性: 空数据/异常输入不崩溃
- 可测试性: 关键逻辑可通过 Node 脚本测试
