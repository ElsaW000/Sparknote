# Chat Tab — AI 对话 Session 入口

> 路由：`pages/chat/index` | tabBar Tab 3  
> 线框图：`/tab-design.html` Row 1 · Tab 3（Chat）

---

## 1. 页面目的

**不是聊天界面**，而是 Session 发起入口。用户在这里选择对话模式后进入全屏对话页，本页本身**没有输入框**。

## 3. 关键交互

| 触发 | 行为 |
|------|------|
| 点击 [＋ 新建会话] | 展开 Session 初始化卡片 |
| 点击任意模式行 | navigateTo `pages/chat/session?mode=xxx` |
| 点击历史会话行 | navigateTo `pages/chat/session?sessionId=xxx`（恢复对话）|

---

## 4. 对话模式说明

| 模式 | 图标 | 说明 | AI 行为 |
|------|------|------|---------|
| 记忆纠偏 | 🧠 | 发现误解与惯性记忆，重新校准认知 | 读取 personal_content，指出偏差 |
| 大师导师 | 👤 | 选择一位 Mentor，深度探讨问题 | 进入 session 后先选角色 |
| 创作辅助 | ✍ | 基于 Library 碎片，辅助写作输出 | 读取 personal_content + reference_content |
| 生成报告 | 📋 | 整理对话 & 碎片，输出结构化报告 | 跳转至报告生成流程 |
