## 1. 页面目的

快速录入文字 → AI 整理生成标签/摘要/清洁文本 → 保存到 Library。同时提供进入 Workspace 的入口卡片，以及**记忆纠偏**功能（P1 新增）。

**定位升级**：不只是"整理工具"，而是**个人成长的沉淀伙伴**——帮助用户看清自己的认知惯性，挑战固有思维。

## 4. 记忆纠偏功能（P1 新增）

### 背景
面向**对个人成长有要求**的用户：他们不只想整理信息，更想被 AI "挑战"——发现自己的认知盲区和惯性思维。

### 触发方式
用户在输入框中写下自己的想法/观点/感悟 → 点 **[纠偏 ◈]**

### AI 行为
```
用户输入（观点/感悟/想法）
        ↓
aiService.biasCheck(text, userHistory?)
  prompt 结构：
  - 识别用户表述中的认知倾向
  - 从反向/侧面提出挑战性问题
  - 结合 Library 中已有片段（如相关）
        ↓
返回 {
  tendency: "你倾向于认为...",
  challenge: "但从另一个角度...",
  questions: ["如果...会怎样？", "你是否考虑过...？"]
}
        ↓
展示纠偏分析 + [保存此反思到 Library]
```

### 设计原则
- **不是否定用户**，而是"帮你看见自己看不见的角落"
- 语气参考：苏格拉底式提问、导师式启发，而非教条式纠错
- 未来可通过**大师口吻 Skills**（用户自定义）调整 AI 风格（如"稻盛和夫风格"、"查理·芒格风格"）

## 5. 二期规划：导师沟通（P2）

> 用户可选择一位"灵魂导师"角色，与 AI 进行深度对话，AI 以该大师的思维框架和口吻回应。

| 功能 | 说明 |
|------|------|
| 大师角色选择 | 用户选择导师风格（基于用户自定义 Skills 文件）|
| 对话式交互 | 多轮对话，AI 记忆当次上下文 |
| 结合 Library | AI 可引用用户的历史片段进行针对性回应 |
| 反思记录 | 对话中的洞见可一键保存到 Library |

**前置条件**：P1 记忆纠偏功能稳定 + 大师口吻 Skills 体系建立
