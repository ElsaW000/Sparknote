# Library Browser — 全量碎片浏览（S3）

> 路由：`pages/library/browser` | 子页面（navigateTo）  
> 入口：Library 主页右上角 ≡  
> 线框图：`/tab-design.html` Row 2 · S3

---

## 1. 页面目的

展示全量碎片列表，支持按类型筛选、搜索、排序，是 Library Tab 的"完整视图"。

---

## 2. 页面结构

```
┌─────────────────────────────────┐
│ ← 全部碎片               [⌕]  │
├─────────────────────────────────┤
│ [我的想法] [参考资料] [全部]    │  ← 第一级大类 tabs
├─────────────────────────────────┤
│ [💡 想法 28] [🎙 录音 7] [✍ 日记 4] │  ← 第二级细分 chips（随大类切换）
├─────────────────────────────────┤
│ 排序: 最近添加 ↓  [时间] [标签] [类型] │
├─────────────────────────────────┤
│ ── 2026-05 ──                   │  ← 日期分组标题
│ ┌────────────────────────────┐  │
│ │ 💡 想法  #认知  2026-05-28 │  │
│ │ "努力不一定有回报…"         │  │
│ └────────────────────────────┘  │
│ ┌────────────────────────────┐  │
│ │ 📖 书摘  #成长  2026-05-10 │  │
│ │ 《原则》第三章：…           │  │
│ └────────────────────────────┘  │
│ ── 2026-04 ──                   │
│ …                               │
│ [加载更多]                       │
└─────────────────────────────────┘
```

---

## 3. 筛选逻辑

| 第一级（大类）| 第二级细分（chips）| 查询条件 |
|-------------|-----------------|----------|
| 我的想法 | 💡 想法 / 🎙 录音 / ✍ 日记 | `content_type = 'personal_content'` + 细分 type |
| 参考资料 | 📖 书摘 / 🌐 网页 / 📎 文件 | `content_type = 'reference_content'` + 细分 type |
| 全部 | 全部细分类型 | 无过滤 |

---

## 4. 关键交互

| 触发 | 行为 |
|------|------|
| 点击碎片卡片 | navigateTo `pages/library/editor?id=xxx` |
| 点击 [⌕] 图标 | 展开搜索框，实时过滤 |
| 切换大类 tab | 第二级 chips 更新为对应细分类型 |
| 点击细分 chip | 按具体细分类型过滤列表 |
| 下滑到底部 | 加载更多（分页，每页 20 条）|
