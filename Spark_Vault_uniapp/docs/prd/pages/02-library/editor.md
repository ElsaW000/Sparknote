# Library Editor — 全屏碎片编辑（S2）

> 路由：`pages/library/editor` | 子页面（navigateTo）  
> 入口：Library 主页 ⤢ 图标、📷/🎙/🌐 快捷按钮、碎片卡片点击  
> 线框图：`/tab-design.html` Row 2 · S2

---

## 1. 页面目的

全屏录入/编辑一条碎片，支持正文输入、类型标注、标签、关联来源，保存后返回 Library 主页。

## 3. 碎片类型与 content_type 映射

| 选择的类型 | content_type |
|-----------|--------------|
| 💡 我的想法（含日记、录音） | `personal_content` |
| 📖 参考摘录（含网页、文件） | `reference_content` |

---

## 4. 关键交互

| 触发 | 行为 |
|------|------|
| 点击 [保存] | 写入 fragments 表 → navigateBack |
| 点击 [取消] | navigateBack（未保存内容丢弃，需确认）|
| 点击 📷 | 拍照/选图 → 插入图片块，触发 OCR 识别 |
| 点击 🎙 | 开始录音 → 完成后插入语音播放条 |
| 点击 🔗 | 弹出 URL 输入框 → 插入 URL 预览卡 |
| 点击 📎 | 选择文件 → 上传并插入文件块 |
| 编辑模式（有 id） | 预填已有数据，[保存] 改为 UPDATE 操作 |

---

## 5. 新建 vs 编辑

- **新建**：URL 参数无 `id`，[保存] 调用 INSERT
- **编辑**：URL 参数有 `id=xxx`，[保存] 调用 UPDATE；左上角增加 [删除] 选项
