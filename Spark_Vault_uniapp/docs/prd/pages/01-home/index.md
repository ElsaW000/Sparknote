> 路由：`pages/home/index` | tabBar Tab 1  
> 源文件：`src/pages/home/index.vue`  
> 线框图：`/tab-design.html` Row 1 · Tab 1（Home）

## 1. 页面目的

用户打开 App 的第一眼，呈现成长积累概览：记录了多少碎片、最近有什么动态、快捷进入 Library / Chat / 报告。

## 3. 数据来源

| 数据 | 来源 |
|------|------|
| 碎片总数 | fragments 表 COUNT |
| 本周录入 | fragments 表，created_at 在本周内 COUNT |
| 对话次数 | chat_sessions 表 COUNT |
| 生成报告 | reports 表 COUNT |
| AI Digest 文本 | DashScope API 定时生成，基于 personal_content |
| 报告历史列表 | reports 表 ORDER BY created_at DESC LIMIT 3 |

刷新时机：`onShow` → 拉取各项统计

---

## 4. 交互行为

| 操作 | 跳转方式 | 目标 |
|------|----------|------|
| [💬 开始纠偏对话] | `navigateTo` | `pages/chat/session?mode=bias`（记忆纠偏 Session）|
| 点击报告历史行 | `navigateTo` | `pages/report/detail?id=xxx` |

## 5. 空状态引导

首次使用（碎片为 0）时，隐藏统计区，显示：  
"还没有记录，去写下今天的第一个想法吧 →"（跳转 Library）
