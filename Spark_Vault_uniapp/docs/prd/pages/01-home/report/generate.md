# Report Generate — 生成新报告（S4b）

> 路由：`pages/report/generate` | 底部 Sheet（showModal 或 navigateTo）  
> 入口：报告列表页 [✨ 新报告] 按钮  
> 线框图：`/tab-design.html` Row 2 · S4b

---

## 1. 页面目的

用户配置报告参数（类型、时间范围、聚焦话题），发起 AI 生成成长报告。以底部 Sheet 形式呈现（半透明遮罩 + 白色面板从底部滑入）。

---

## 2. 页面结构

```
┌─────────────────────────────────┐
│ （半透明遮罩）                   │
│                                 │
│ ┌─────────────────────────────┐ │
│ │ 生成新报告         ✕        │ │  ← Sheet 标题 + 关闭
│ ├─────────────────────────────┤ │
│ │ 报告类型                    │ │
│ │ [成长反思] [创作风格] [专题] │ │  ← 单选 pill
│ ├─────────────────────────────┤ │
│ │ 时间范围                    │ │
│ │ [最近7天] [最近30天] [自定义]│ │  ← 单选 pill
│ ├─────────────────────────────┤ │
│ │ 聚焦话题（可选）             │ │
│ │ [▼ 选择话题…]              │ │  ← 从已有标签中选
│ ├─────────────────────────────┤ │
│ │ [✨ 开始生成报告]            │ │  ← 主 CTA
│ │ 预计生成时间：30 秒          │ │  ← 提示文字
│ └─────────────────────────────┘ │
└─────────────────────────────────┘
```

---

## 3. 报告类型说明

| 类型 | AI 分析角度 |
|------|------------|
| 成长反思 | 时间段内想法的变化、重复主题、潜在矛盾 |
| 创作风格 | 用词偏好、表达习惯、思维模式 |
| 专题深度 | 围绕某个话题的所有记录深度分析 |

---

## 4. 关键交互

| 触发 | 行为 |
|------|------|
| 点击遮罩 / ✕ | 关闭 Sheet |
| 选择"自定义"时间范围 | 展开日期选择器 |
| 选择聚焦话题 | 弹出已有标签列表（来自 fragments 表的 tags）|
| 点击 [✨ 开始生成报告] | POST 请求 → AI 生成 → navigateTo `pages/report/detail?id=xxx` |

---

## 5. AI 生成逻辑

```
用户参数 → 查询 fragments 表（content_type = 'personal_content'，按时间/话题过滤）
         → 构造 prompt → DashScope API（qwen-plus）
         → 保存报告到 reports 表
         → navigateTo report/detail
```

**注意**：只分析 `personal_content`，不分析 `reference_content`。
