# Report — 成长报告列表（S4）

> 路由：`pages/report/index` | 子页面（navigateTo）  
> 入口：Home 快捷按钮"📊 查看报告"  
> 线框图：`/tab-design.html` Row 2 · S4

---

## 1. 页面目的

展示所有历史成长报告，提供生成新报告的入口，可点击查看任意一份报告详情。

---

---

## 3. 关键交互

| 触发 | 行为 |
|------|------|
| 点击 [+ 生成新报告] | 从底部弹出 `pages/report/generate`（S4b sheet）|
| 点击报告卡片 | navigateTo `pages/report/detail?id=xxx` |
| 空态按钮 | 同上，弹出生成 sheet |

---

## 4. 数据结构

| 字段 | 说明 |
|------|------|
| `report_type` | 成长反思 / 创作风格 / 专题深度 |
| `time_range` | 最近7天 / 最近30天 / 自定义 |
| `topic` | 聚焦话题（可选）|
| `session_stats` | 各类型对话次数（记忆纠偏×N / 导师×N / 创作×N），显示在卡片 chip 行 |
| `created_at` | 生成时间，用于按年月分组 |
