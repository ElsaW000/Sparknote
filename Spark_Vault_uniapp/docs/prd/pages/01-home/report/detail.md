# Report Detail — 报告详情（S5）

> 路由：`pages/report/detail?id={id}` | 子页面（navigateTo）  
> 入口：报告列表页点击报告卡片；生成完成后自动跳转  
> 线框图：`/tab-design.html` Row 2 · S5

---

## 1. 页面目的

展示一份完整成长报告：AI 生成的分析内容 + 支撑分析的碎片引用来源。

---

---

## 3. 数据结构

| 字段 | 说明 |
|------|------|
| `report.content` | AI 生成的 Markdown 格式报告正文 |
| `report.fragment_ids` | 本次分析引用的 fragment id 列表 |
| `report.report_type` | 成长反思 / 创作风格 / 专题深度 |
| `report.time_range` | 分析覆盖时间段 |

---

## 4. 关键交互

| 触发 | 行为 |
|------|------|
| 点击"立即开始这个对话" | navigateTo `pages/chat/session?mode=bias` |
| 点击 [⎙ 分享] | 生成图片/复制文本（MVP 可先只支持复制）|
| 点击反馈按钮 | 选中态高亮，记录 feedback 到数据库 |
| 提交文字反馈 | 与反馈按钮选择一起保存 |
