# 个性化 / Skills 管理页（S6）

> 路由：`pages/me/skills` | 子页面（navigateTo）  
> 入口：Me Tab → "个性化 / Skills"  
> 线框图：`/tab-design.html` Row 2 · S6

---

## 1. 页面目的

管理用户的 AI 导师 Skills：可开关内置导师模板，创建/编辑自定义导师角色。Chat → 大师导师模式选角色时，启用的导师会出现在选项中。

## 3. Skill 数据结构

| 字段 | 说明 |
|------|------|
| `name` | 导师名称（如"我的创业导师"）|
| `avatar_emoji` | 头像 emoji |
| `style_prompt` | 风格描述（供 AI system prompt 使用）|
| `is_builtin` | 内置 = true（开关可控，不可删除）|
| `is_enabled` | 内置导师是否启用（ON/OFF 开关状态）|

---

## 4. 关键交互

| 触发 | 行为 |
|------|------|
| 切换内置导师开关 | 更新 `is_enabled`；OFF 的导师不出现在 Chat 角色选择中 |
| 点击自定义 Skill 行（›）| navigateTo 编辑页：修改名称 & 风格描述 |
| 长按自定义 Skill | 进入编辑模式（同点击 ›）|
| 点击"+ 创建新 Skill" | 弹出/跳转表单：名称 + 风格描述 → 保存 |
