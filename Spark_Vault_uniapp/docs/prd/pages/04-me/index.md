# Me Tab — 个人设置

> 路由：`pages/me/index` | tabBar Tab 4  
> 源文件：`src/pages/me/index.vue`  
> 线框图：`/tab-design.html` Row 1 · Tab 4（④ Me）

---

## 1. 页面目的

用户的个性化设置中心：头像/昵称、AI 导师管理（Skills）、应用偏好、账号信息。

---

## 3. 关键交互

| 触发 | 行为 |
|------|------|
| 点击用户信息行 | navigateTo 个人资料编辑页 |
| 点击"个性化 / Skills" | navigateTo `pages/me/skills`（S6 Skills 管理）|
| 点击"退出登录" | 清除 token → 跳转登录页（红色文字，需二次确认）|

---

## 4. Skills（AI 导师）说明

- 用户可在 `pages/me/skills`（S6）管理内置导师的启用状态（开关）
- 用户可创建自定义 AI 导师角色（名称、风格描述）
- 创建的导师在 Chat → 大师导师模式的角色选择中可用
