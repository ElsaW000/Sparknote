## 1. 产品概述

**产品名称**: Spark Vault  
**产品定位**: 个人成长反思工具 — 帮助用户沉淀记录、发现记忆偏差、与智慧导师对话  
**核心价值**: 记录 → 沉淀 → 洞见 → 成长

> 不是让 AI 替你写内容，而是帮你**看清自己**：你以为你记得的、你以为你理解的，和实际是否一致？

---

## 2. 目标用户

| 用户 | 痛点 | 核心诉求 |
|------|------|----------|
| 对个人成长有要求的人 | 持续记录但缺少沉淀，看不到自己的思维惯性 | 沉淀 → 成长，发现记忆/认知偏差 |
| 内容创作者 | 灵感碎片散落各处，难以激活组合 | 碎片收集 + AI 辅助激活 |
| 知识工作者 | 阅读积累多但提炼少，缺乏外部视角 | 碎片 → 结构化报告 + 深度对话 |

---

## 3. 核心功能

### 3.1 碎片收集（Library Tab）

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 快速文字录入 | Library 顶部 textarea，随时记录想法 | P0 |
| 拍照 / OCR 识别 | 拍书页/截图，识别文字内联展示 | P0 |
| 语音录音 | 录制原始音频（.m4a），STT 按需转写 | P0 |
| 网页 / 链接收藏 | 粘贴 URL 自动解析标题和摘要 | P0 |
| 全屏碎片编辑（Notion 式）| 内联文字 + 图片 + 录音 + URL 预览卡 | P0 |
| 碎片类型分类 | personal_content（我的内容）/ reference_content（参考资料） | P0 |
| 全量浏览 / 筛选 | 按类型、日期、标签浏览所有碎片 | P1 |

### 3.2 AI 对话（Chat Tab）

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 记忆纠偏对话 | AI 读取 personal_content，指出用户可能记错或误解的地方 | P0 |
| 大师导师对话 | 以稻盛和夫/查理·芒格/苏格拉底等风格与用户深度对话 | P0 |
| 创意激发对话 | AI 基于碎片库提出新视角和创作方向 | P1 |
| 自由探索 | 无角色约束的开放对话，AI 引用用户记录 | P1 |
| 自定义 Skills | 用户自定义 AI 角色的 system prompt | P1 |

**重要约束**：Chat Tab 本身无输入框，只作 Session 发起入口；实际对话在全屏 Session 页进行。

### 3.3 成长报告（Home Tab / 报告页）

| 功能 | 描述 | 优先级 |
|------|------|--------|
| AI 周报自动生成 | 基于本周对话和碎片，自动生成成长摘要 | P0 |
| 手动生成报告 | 用户选择类型（成长反思 / 创作风格 / 专题深度）+ 时间范围 + 话题 | P0 |
| 报告详情 | 核心洞察 + 思维模式 + 建议下一步 | P0 |
| 用户反馈 | ✅ 基本准确 / ⚠️ 不完全对 / 🙅 没这么严重 + 文字补充 | P0 |

### 3.4 个性化设置（Me Tab）

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 内置导师模板 | 稻盛和夫 / 查理·芒格 / 苏格拉底（toggle 启用）| P0 |
| 自定义 Skills | 创建和管理自定义 AI 角色 | P1 |
| 账号与设置 | 通知、隐私、会员状态 | P1 |

## 4. 核心概念说明

### 记忆纠偏（不是"认知纠偏"）

帮助用户发现：他以为自己记得/理解的某件事，和实际情况存在偏差。  
范围更具体：**不是评判所有想法对不对**，而是聚焦"记错了 / 理解偏了"这一类问题。  
数据来源：仅读取 `personal_content` 类型碎片，`reference_content` 不纳入分析。

### 碎片类型划分

```
personal_content  →  AI 分析（记忆纠偏/导师引用）
  💡 想法 / ✍ 日记 / 🎙 录音

reference_content  →  AI 引用知识库（不分析偏差）
  📖 书摘 / 🌐 网页 / 📎 文件
```

## 5. 用户主流程

```
每日记录
  用户在 Library 随手录入碎片（文字/图片/录音/链接）
       ↓
定期对话
  从 Chat 发起 Session → 选记忆纠偏/导师模式 → 全屏对话
  AI 读取 personal_content，引用具体碎片作为依据
       ↓
生成报告
  Home 页查看 AI 周报 / 手动生成专题报告
  阅读洞察 → 给出反馈 → AI 下次更精准
       ↓
Skills 调优
  Me → Skills 调整导师风格 / 创建新角色
```

## 3. 核心功能

### 3.1 知识库

**把历史变成训练数据**

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 导入文章 | 导入用户历史写的内容（微信文章、博客、文档） | P0 |
| 素材库 | 自动抓取保存的链接/图片/视频内容 | P0 |
| 文章理解 | AI 分析内容，提取风格、观点、结构 | P0 |
| 标签分类 | 自动打标签、主题分类 | P1 |

### 3.2 个性化 Agent

**AI 学你的风格**

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 风格学习 | 分析用户历史文章，学写作风格 | P0 |
| 声音定制 | 定义 Agent 的说话方式（严肃/轻松/专业） | P0 |
| 预设角色 | 提供多种角色（写作搭子、产品经理、自媒体创作者） | P0 |
| 自定义角色 | 用户自己配置 Agent 的系统提示词 | P1 |

### 3.3 生产型输出

**直接出可用内容，不是半成品**

| 功能 | 描述 | 优先级 |
|------|------|--------|
| 脚本生成 | 输入选题，直接出可拍的脚本 | P0 |
| 文案生成 | 按平台风格输出（小红书/B站/微信） | P0 |
| PRD 生成 | 输入想法，自动出完整 PRD | P0 |
| 内容扩展 | 一句话灵感扩展成完整文章 | P0 |

### 3.4 创作工作台

**对话式交互**

| 功能 | 描述 | 优先级 |
|------|------|--------|
| AI 对话 | 基于知识库和 Agent 风格对话 | P0 |
| 快捷输入 | 一句话开始创作 | P0 |
| 历史追溯 | 引用之前的相关内容 | P0 |
| 多轮创作 | 连续对话优化内容 | P1 |
