## 1. 设计哲学与核心原则

### 1.1 极简专注 (Minimalism)
界面元素服务于内容。大面积留白、清晰层级，让用户专注于当下的灵感。

### 1.2 Vault 隐喻
区别于 chat 风格的 flomo，Spark Vault 强调"收藏 → 沉淀 → 激活"的闭环。片段是原材料，报告是产出物。

### 1.3 流畅的 AI 协作
AI 不是独立工具，而是深度集成在整理、合成流程中的"第二大脑"。

## 3. 导航结构（4-Tab 新架构）

> 旧架构（Home / Library / Capture / Insight）已废弃。Capture 并入 Library，Insight 改名为 Chat 并重新定位。

```
tabBar（4 个固定 Tab）
├── 🏠 Home      pages/home/index
├── 📚 Library   pages/library/index
├── 💬 Chat      pages/chat/index
└── 👤 Me        pages/me/index

子页面（navigateTo，全屏覆盖）
├── pages/chat/session          S1/S1b  全屏对话页（含导师选角色 → 对话中两种状态）
├── pages/library/editor        S2      全屏碎片编辑页（Notion 式内联编辑）
├── pages/library/browser       S3      碎片全量浏览页（Library ≡ 入口）
├── pages/report/list           S4      报告历史列表页
├── pages/report/generate       S4b     生成新报告底部面板（Sheet，非独立页）
├── pages/report/detail         S5      报告详情页
└── pages/me/skills             S6      个性化 / Skills 管理页
```

### 3.1 Tab 切换规则
- Tab 间跳转：`uni.switchTab({ url })`
- 子页面跳转：`uni.navigateTo({ url })`
- 返回：`uni.navigateBack()`

## 4. 各 Tab 详细设计

### 4.1 Home Tab

| 区域 | 内容 |
|------|------|
| 统计区 | 2×2 格：碎片总数、本周新增、对话次数、报告数 |
| AI 周报 | 渐变卡片，AI 自动生成，点击展开 |
| 报告历史 | 列表 + "查看全部"入口（→ S4） |

**核心决策**：报告不单独一个 Tab，归入 Home；统计数字用深海蓝大号字体。

---

### 4.2 Library Tab

| 区域 | 内容 |
|------|------|
| 录入卡片 | 顶部 `textarea`（随手记录）+ 右下角 ⤢ 进入全屏编辑（→ S2） |
| 快捷操作行 | 📷 拍照/OCR · 🎙 录音 · 🌐 网页链接（点击弹出对应操作） |
| 碎片列表 | 个人内容 / 参考资料 双类型 chip 筛选 + 时间倒序列表 |
| 右上角 ≡ | 进入全量浏览（→ S3） |

**核心决策**：
- Capture Tab 不再单独存在，录入功能内嵌 Library 顶部
- 语音录音：始终保存原始音频（.m4a），STT 按需触发，不自动转写
- ⤢ 图标：`position:absolute; right:7px; bottom:7px`，进入 S2 全屏编辑

---

### 4.3 Chat Tab

| 区域 | 内容 |
|------|------|
| Session 启动区 | 4 张模式卡：记忆纠偏 / 大师导师 / 创意激发 / 自由探索 |
| 历史对话列表 | 每行：模式图标 + 对话标题 + 最后一句话预览 + 时间 |

**核心决策**：
- Chat Tab **无输入框**，只是 Session 发起入口
- 点击任意模式卡 → 进入全屏 Session 页（S1）
- 对话内容不保存为碎片，只保存会话记录

---

### 4.4 Me Tab

| 区域 | 内容 |
|------|------|
| 用户信息 | 头像 + 昵称 + 会员状态 |
| 功能组 1 | 个性化 / Skills（→ S6） · 通知设置 |
| 功能组 2 | 关于 / 帮助 · 退出登录 |

**参考**：Claude App 的 Me Tab 样式（简洁设置列表）。

## 5. 子页面详细设计

### S1 · 全屏对话页（导师模式，角色选择状态）

- 顶部导航：← 返回 + 对话模式标题 + ⋯ 菜单
- 首次进入显示**角色选择卡片**（AI 以第一条消息的形式呈现）：稻盛和夫 / 查理·芒格 / 苏格拉底 / 自定义
- 底部：输入框（灰色占位，"回复…"）+ 发送按钮（初始禁用）

### S1b · 全屏对话页（对话进行中）

- 角色选择后过渡，显示气泡对话流
- AI 气泡：白底圆角 + 来源引用脚注（"引用你的记录：XXX"）
- 用户气泡：深海蓝实底 + 右对齐
- 底部输入框激活态

### S2 · 全屏碎片编辑页（Notion 式）

- 顶部：取消 · 新建碎片 · 保存
- 类型切换行：💡 我的想法（personal）/ 📖 参考摘录（reference）
- 主体画布（一个连续 flex 列）：
  - 标题行（可选，contenteditable）
  - 正文段落
  - 内联图片（粘贴后展示 + OCR 识别结果折叠）
  - 内联录音条（▶ 播放 + 进度条 + 时长）
  - URL 预览卡（粘贴链接自动解析）
  - 标签行
- 底部工具栏：
  - 格式行：B I U H · 列表 · 引用
  - 附件行：📷 图片 · 🎙 录音 · 🔗 链接 · 📎 文件

### S3 · 碎片全量浏览页

- 顶部：← 返回 + 全部碎片 + ⌕ 搜索
- 筛选区（背景 `#f5f2ee`）：
  - 大类 pill：我的想法 / 参考资料 / 全部
  - 细分 chip：💡 想法 N · 🎙 录音 N · ✍ 日记 N
  - 排序：最近添加 / 时间 / 标签 / 类型
- 碎片列表：按日期分组，支持上拉加载

### S4 · 报告历史列表页

- 顶部：← 返回 + 报告历史 + **+ 生成新报告**（触发 S4b Sheet）
- 列表：按月分组，每条报告显示图标 + 标题 + 日期 + 简述 + 类型 chip
- 点击报告 → S5 报告详情

### S4b · 生成新报告（底部 Sheet）

- 触发方式：S4 页面点击"+ 生成新报告"按钮
- 半透明遮罩 + 底部圆角 Sheet
- 字段：
  - **报告类型**：成长反思 / 创作风格 / 专题深度
  - **时间范围**：最近7天 / 最近30天 / 自定义
  - **聚焦话题**（可选下拉，默认"全部话题"）
- 底部：✨ 开始生成报告 + "预计30秒"提示

### S5 · 报告详情页

- 顶部：← 返回 + 报告标题 + ⎙ 分享
- 内容区块：
  - 📌 核心洞察
  - 🔁 反复出现的思维模式
  - 💡 建议下一步（含"立即开始这个对话"跳转 → S1）
  - 💬 用户反馈区：✅ 基本准确 / ⚠️ 不完全对 / 🙅 没这么严重 + 文字补充框

**概念说明**：报告分析"记忆纠偏"而非"认知纠偏"——帮助用户发现自己对某件事的记忆或理解与实际存在偏差，而非评判所有想法。

### S6 · Skills 管理页

- 顶部：← 返回 + 个性化 / Skills
- 内置导师模板（可 toggle 开关）：🏮 稻盛和夫 / 🎩 查理·芒格 / 🏛️ 苏格拉底
- 我的自定义 Skills：列表 + 右箭头进入编辑
- 底部：+ 创建新 Skill 按钮

## 6. 碎片数据模型

碎片（Fragment）区分两种类型，影响 AI 的读取行为：

| 字段值 | 显示名 | 来源 | AI 行为 |
|--------|--------|------|---------|
| `personal_content` | 💡 想法 / ✍ 日记 / 🎙 录音 | 用户主动创建 | AI 读取，用于记忆纠偏 / 导师分析 |
| `reference_content` | 📖 书摘 / 🌐 网页 / 📎 文件 | 外部导入 | AI 引用（知识库），不纳入偏差分析 |

> 录音归类：用户录音完成后手动选择归类（personal / reference），系统不自动判断。

## 7. 交互规范

### 7.1 操作反馈
- 成功：`uni.showToast({ title: '...', icon: 'success' })`
- 失败：`uni.showToast({ title: error, icon: 'none' })`
- 危险操作：`uni.showModal` 二次确认

### 7.2 空状态保护
- 所有主要操作按钮使用 `:disabled="!form.xxx"` 防空提交

### 7.3 录音规范
- 录制完成后立即保存原始音频（.m4a）
- STT 按需触发（用户点击"转写"时）
- 录音碎片在列表中显示 ▶ 播放条 + 时长
